<h1>RootChess</h1>
 <br>
*RootChess* - это шахматный движок с открытым исходным кодом, написанный на Python с использованием Pygame. Проект создан в рамках индивидуального проекта по информатике, но планируется расширения функционала в будущем, по мере приобретения навыков разработчика.

## Особенности
- Уникальные пиксельные фигуры
- Встроенные темы
- История всех ходов на боковой панели
- Код полностью открыт для изучения

Чтобы собрать из этого приложение(windows), сохраните все файлы в одну папку и в терминале введите: 
python -m PyInstaller --noconfirm --onefile --windowed
--icon="иконка.ico" --add-data "images;images" --add-data "images1;images1"
--add-data "images2;images2" --add-data "images3;images3"
--add-data "images4;images4" --add-data "шрифт.ttf;."
--add-data "иконка.ico;." --add-data "меню0.png;."
--add-data "меню1.png;." --add-data "меню2.png;."
--name "RootChess" code.py

Так как история ходов сохраняется, имеется отдельный файл с логом ходов(save.pgn). Чтобы не засорять свой рабочий стол, можно убрать созданный exe в надежное место и сделать для него ярлык, при необходимости иконку можно будет взять из папки проекта.
